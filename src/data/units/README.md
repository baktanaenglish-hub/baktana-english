## כללים (מלאים ב־v2.md §5.4)
1. **לא משנים `id` של שיעור קיים ולא את הסדר שלו.** שיעור חדש מתווסף רק **בסוף** היחידה, עם המספר הבא (`u2l3` אחרי `u2l2`).
2. **לא מוחקים ולא מסדרים מחדש משפטים בשיעור קיים** – מפתח החזרה של משפט הוא המיקום שלו (`s:u4l3:2`). מותר להחליף תוכן של משפט רק במקומות שמופיעים ברשימת הניקוי ב־v2.md §4.0.
3. 5 מילים ו־3–4 משפטים לשיעור. כל `en` (לפי `wordId`) וכל `he` של מילה ייחודיים **בכל הקורס**. לכל מילה `sound`.
4. משפט שיש בו מגדר בעברית מקבל `heAlt` עם צורת הנקבה.
5. כל משפט חדש מקבל `errors` (קודי E1–E27).
6. אחרי כל שינוי: `npm test` (כולל `src/data/content.test.ts` ובדיקת הפתירות ב־`src/lib/exercises.test.ts`).
