הדרך הפשוטה להחזיר אותם: להחיל את ה־diff שבסוף המסמך:

```bash
awk '/^```diff$/{f=1;next} f&&/^```$/{f=0} f' docs/legal-premium-draft.md | git apply
```

    ל־RevenueCat.
  </li>
</ul>

  (Google Play ← תשלומים ומינויים).
</p>
