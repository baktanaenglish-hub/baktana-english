# Baktana English – מסמך דרישות מוצר (PRD)

> גרסה: 0.2 · סטטוס: טיוטה לשחרור "חשבונות וסנכרון" · בעלים: צוות מוצר

## 1. חזון

Baktana English היא אפליקציית ווב ללימוד אנגלית **לדוברי עברית**, בסגנון Duolingo: שיעורים קצרים (3–5 דקות), משחקיים, שנבנים זה על זה במסלול אחד ברור.
ההבדל שלנו: התוכן נכתב **מנקודת המבט של ישראלים** – הממשק בעברית (RTL), ההסברים בעברית, והתרגילים מכוונים במיוחד לטעויות הנפוצות של דוברי עברית (השמטת is/am/are, a/the, סדר שם תואר, "I am 20 years" ועוד – ראו [curriculum.md](./curriculum.md)).

**משפט המטרה:** כל ישראלי – ילד, הורה או סבא – יכול לפתוח את האתר, להתחיל ללמוד בתוך 10 שניות בלי הרשמה, ולהגיע לרמת A2 בתוך כמה חודשים של 10 דקות ביום.

## 3. הלולאה המרכזית (Core Loop)

```
פותחים את האפליקציה → רואים את המסלול ואת השיעור הבא ("התחילו!")
   → שיעור: ~12–14 תרגילים (מילים → התאמה → בניית משפטים → האזנה)
      → טעות = לב אחד פחות, והתרגיל חוזר בסוף
   → מסך סיום: +XP, דיוק, רצף 🔥
   → השיעור הבא נפתח → חוזרים מחר כדי לשמור על הרצף
```

מנופי חזרה: רצף ימים, יעד יומי (30 XP), לוח מובילים שבועי, לבבות שמתמלאים עם הזמן.

## 4. כללי משחק (מקור אמת: `src/lib/progress.ts`)

| כלל | ערך |
|---|---|
| לבבות מקסימום | 5 |
| מילוי לב | 1 לב כל 30 דקות, עד 5 |
| מחיר טעות | לב אחד (בתרגילי בחירה ובניית משפט; בתרגיל התאמת זוגות טעות לא עולה לב) |
| טעות בתרגיל | התרגיל נוסף שוב לסוף התור; השיעור מסתיים רק כשכל התרגילים נענו נכון |
| XP לשיעור | 10, ועוד בונוס 5 אם לא הייתה אף טעות (סה״כ 15) |
| חזרה על שיעור שהושלם | מותרת, מעניקה XP שוב ומגדילה את מונה ההשלמות |
| דיוק | `round(תרגילים / (תרגילים + טעויות) × 100)` |
| יעד יומי | 30 XP (`DAILY_GOAL_XP`), מתאפס בתחילת יום מקומי חדש |
| רצף | +1 בשיעור הראשון של יום שבא מיד אחרי יום פעיל; מתאפס ל־1 אם דילגו על יום; מוצג כ־0 אם היום האחרון הפעיל לפני אתמול |
| פתיחת שיעורים | לפי סדר הקורס: שיעור נפתח רק אחרי שהשיעור שלפניו הושלם פעם אחת לפחות |

- בינה מלאכותית שמייצרת תרגילים בזמן אמת.

## 6. מדדי הצלחה

| מדד | הגדרה | יעד (3 חודשים) |
|---|---|---|
| **Time-to-first-exercise** | זמן מפתיחת האתר עד תרגיל ראשון | < 10 שניות, 0 טפסים |
| **השלמת שיעור ראשון** | % מבקרים חדשים שמסיימים שיעור 1 | ≥ 60% |
| **D1 / D7 retention** | % שחוזרים יום אחרי / שבוע אחרי | ≥ 35% / ≥ 15% |
| **רצף ממוצע** | אורך רצף ממוצע של משתמשים פעילים | ≥ 4 ימים |
| **המרה להרשמה** | % אורחים שנרשמים אחרי שיעור 3 | ≥ 20% |
| **השגת יעד יומי** | % ימים פעילים שבהם הושג יעד 30 XP | ≥ 50% |
| **דיוק ממוצע** | דיוק ממוצע בשיעור | 75%–90% (קשה מדי/קל מדי מחוץ לטווח) |
| **יציבות** | שגיאות JS לא מטופלות / סשן | < 0.5% |

## 7. דרישות לא־פונקציונליות

- **ביצועים:** טעינה ראשונה < 2 שניות ב־4G; חבילת JS < 200KB gzip.
- **אופליין:** כל הלימוד עובד ללא רשת (התוכן מובנה בחבילה). רק הרשמה, סנכרון ולוח מובילים דורשים רשת.
- **פרטיות:** לא אוספים מידע מעבר לאימייל, שם תצוגה והתקדמות. סיסמאות נשמרות כ־hash בלבד. בלוח המובילים מוצג רק שם התצוגה.
- **נגישות:** ניגודיות AA, כל כפתור עם תווית בעברית, שימוש במקלדת.
- **דפדפנים:** שתי הגרסאות האחרונות של Chrome, Safari (כולל iOS), Firefox, Edge.
