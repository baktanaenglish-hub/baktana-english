# Baktana English 🇬🇧

> השם הציבורי של האפליקציה הוא **Baktana English**. מזהה גרסת Google Play הוא `com.baktana.english`, וה־APK להורדה מ־GitHub הוא `com.baktana.english.sideload`.

אפליקציה ללימוד אנגלית לדוברי עברית, בסגנון דואולינגו: מסלול של יחידות ושיעורים קצרים שנפתחים אחד אחרי השני, עם לבבות, XP, רצף ימים, יעד יומי וליגה שבועית.
אפשר ללמוד כאורח בלי הרשמה (ההתקדמות נשמרת במכשיר), ואפשר ליצור פרופיל כדי לסנכרן בין מכשירים ולהתחרות בליגה.

## מה יש באפליקציה

- **מסלול לימוד** – 12 יחידות ו־64 שיעורים (רמות Pre‑A1 עד A2): ברכות, משפחה, אוכל, מספרים וזמן, בית ושגרה, הווה פשוט, בעיר, הווה מתמשך, גוף ורגשות, עבר, סיפורים ותוכניות וטיול לחו״ל. שיעור נפתח כשהקודם הושלם, ושיעורים שנוספו לפני המקום שאליו הגעתם נפתחים מיד עם תג **"חדש!"**.
- **טיפ פתיחה ליחידה** 📖 – לפני השיעור הראשון של כל יחידה (ובכל רגע מהכפתור שבכותרת היחידה) מוצג הסבר קצר על המבנה החדש, ולצדו תג רמת CEFR. גם לשיעורים עם מבנה חדש יש טיפ קצר לפני התרגיל הראשון.
- **4 סוגי תרגילים**, שנוצרים אוטומטית מתוכן השיעור: בחירה מרובה, התאמת זוגות, בניית משפט מבנק מילים (לשני הכיוונים) והאזנה (כולל השמעה איטית 🐢).
- **הקלדה** ⌨️ – מיחידה 2 משפט אחד בכל שיעור מתורגם לאנגלית בהקלדה חופשית, ומיחידה 4 גם "הקלידו את מה ששמעתם". אותיות גדולות ופיסוק לא משנים, ושגיאת כתיב קטנה נסלחת (ומוצג האיות הנכון) – אבל לא טעות דקדוק כמו work/works. מקלדת שנשארה בעברית מזוהה ולא עולה לב. בחזרה, משפטים שכבר יודעים טוב (קופסה 3 ומעלה) מוקלדים במקום להיבנות מבנק מילים.
- **השלמת חסר** ✏️ – בכמעט כל שיעור משפט אחד מוצג עם מילה חסרה ובוחרים אותה מבין אפשרויות. החסר נופל על מה שקשה לדוברי עברית: am/is/are, a/an/the, in/on/at, do/does, have/has (ואם אין – על מילה מהשיעור).
- **מבחן סוף יחידה** 🏆 – בסוף כל יחידה, אחרי שכל השיעורים שלה הושלמו: 10 שאלות מכל היחידה, בלי לבבות. 8 נכונות ומעלה – כתר 👑 ליחידה ו־20 XP; פחות – מוצג הציון ואפשר לנסות שוב.
- **מבחן מיקום** 🎯 – למי שכבר יודע קצת אנגלית: 3 שאלות לכל יחידה לפי הסדר; 2 נכונות עוברות יחידה, והמבחן נעצר ביחידה הראשונה שלא עברה. השיעורים של היחידות שעברו מסומנים כהושלמו (בלי XP), והמילים שלהן נכנסות לחזרה החכמה. מוצע במסלול עד שמסיימים שיעור מעבר ליחידה 1.
- **תזכורת יומית** ⏰ – באפליקציית האנדרואיד: התראה בשעה שבוחרים (ברירת מחדל 20:00), שמזכירה את הרצף שעל הפרק; ביום שכבר תרגלו לא תגיע תזכורת. בדפדפן, שלא יכול להתריע כשהאתר סגור, אפשר להוסיף ליומן אירוע יומי עם התראה (‎.ics).
- **לבבות** ❤️ – טעות עולה לב, ולב חדש מתמלא כל 30 דקות. תרגיל שטעו בו חוזר בסוף השיעור.
- **יהלומים 💎** – מטבע פרסים: 5 על כל שיעור (ועוד 5 בלי אף טעות), 3 על חזרה או תרגול, 10 כשעומדים ביעד היומי ו־20 על מבחן יחידה ראשון. בראש המסלול יש **תיבה יומית** 🎁 (5–15 יהלומים, וגדלה ככל שפותחים כמה ימים ברצף) ו־**3 משימות יומיות** עם פרס ובונוס על השלמת כולן. ב**חנות** קונים לבבות בונוס, הקפאת רצף 🧊 (יום שפוספס לא שובר את הרצף) ודמויות לפרופיל. היהלומים נשמרים במכשיר בלבד.
- **משחקים** 🎮 – משחקי מילים עם המילים שכבר למדתם, נפתחים מכרטיס במסלול: **מרוץ מילים** ⚡ (60 שניות, רצף תשובות נכונות מכפיל את הניקוד עד x5, טעות מורידה 3 שניות) נפתח אחרי שמסיימים את כל השיעורים ביחידה 1, ו**זיכרון** 🃏 (6 זוגות קלפים, אנגלית–עברית) נפתח ב־100 יהלומים. 3 המשחקים הראשונים בכל יום מכל סוג נותנים יהלומים, ושבירת שיא מוסיפה בונוס.
- **XP, רצף ימים 🔥 ויעד יומי** (10/20/30/50 XP) שבוחרים במסך הפתיחה.
- **חזרה מרווחת** 🧠 – כל מילה ומשפט נכנסים ל"קופסה" (שיטת לייטנר, 6 קופסאות) לפי התשובה הראשונה. כפתור "חזרה (N)" מראה כמה פריטים מחכים היום, וכרטיס מופיע בראש המסלול כשיש 3 ומעלה. חזרה נותנת 10 XP ולא עולה לבבות; כשאין מה לחזור עליו הכפתור הופך ל"תרגול" 💪. מצב החזרה נשמר במכשיר ומסתנכרן עם החשבון.
- **תשובות בלשון נקבה** – בתרגילי בניית משפט בעברית מתקבלת גם הצורה הנקבית (למשל "אני שמחה").
- **חשבון וסנכרון** – הרשמה/התחברות, מיזוג ההתקדמות המקומית עם השרת, וסנכרון חוזר כשהרשת חוזרת. אורח מקבל הצעה עדינה להירשם אחרי השיעור הראשון (ושוב אחרי החמישי אם דחה).
- **ליגה** 🏆 – דירוג אישי ודירוג קבוצות לפי XP, שבועי, חודשי ומצטבר. גם אורחים יכולים לצפות.
- **קבוצות ואתגרים** 👥 – קבוצות פרטיות עם קוד או קישור הזמנה, אתגרים קבוצתיים שבועיים עם פרסי יהלומים, דירוג הוגן בין קבוצות בגדלים שונים והתראות על התקדמות הקבוצה ([docs/groups.md](docs/groups.md)).
- **פרופיל** – מחיקת חשבון (עם אימות סיסמה), מצב סנכרון, יעד יומי, ערכת נושא (אוטומטי/בהיר/כהה), צלילים ומתג אנליטיקה.
- **אנליטיקה אנונימית** – אירועי שימוש (שיעור התחיל/הסתיים, תשובות, חזרות) נשלחים בקבוצות עם מזהה התקנה אקראי, בלי אימייל, שם או תשובות שהוקלדו; אפשר לכבות בפרופיל. מהאירועים נבנים מדדי הצלחה ודוח "בריאות תוכן". פרטים: [docs/analytics.md](docs/analytics.md).
- **PWA** – אפשר להתקין כאפליקציה בטלפון. מצב כהה, אנימציות, צלילים, נגישות ותמיכה מלאה ב־RTL.

## טכנולוגיות

| חלק | תיקייה | טכנולוגיה |
|---|---|---|
| אפליקציית הווב | `src/` | React 19 + Vite + TypeScript |
| חוזה ה־API המשותף | `shared/api.ts` | טיפוסי TypeScript שמשמשים את שני הצדדים |
| שרת | `server/` | Express 5 + SQLite מובנה של Node (`node:sqlite`), מורץ עם tsx |
| כלים | שורש הפרויקט | Vitest, ESLint, Prettier, GitHub Actions, Docker |

השרת משתמש באותם מודולים טהורים של הלקוח (`src/lib/progress.ts`, `src/data/course.ts`), כך שכללי המשחק זהים בשני הצדדים.

## דרישות

- Node.js 22.15 ומעלה (ראו `.nvmrc`)
- npm

## הרצה בפיתוח

```bash
npm install        # מתקין גם את התלויות של server/ (postinstall)
npm run dev        # Vite על http://localhost:5173 + שרת ה־API על פורט 3001
```

Vite מעביר (proxy) כל בקשה ל־`/api` אל השרת. אם השרת לא רץ, האפליקציה עובדת במצב אורח בלבד.
אפשר גם להריץ כל צד לבד: `npm run dev:web` או `npm run dev:server`.

### משתני סביבה

מעתיקים את `.env.example` ל־`.env` (בשורש או ב־`server/`) ומעדכנים. משתנים שכבר מוגדרים בסביבה גוברים על הקובץ.

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `PORT` | `3001` | הפורט של השרת |
| `DATABASE_PATH` | `./data/baktana.db` | קובץ ה־SQLite (נוצר אוטומטית) |
| `JWT_SECRET` | – | סוד לחתימת טוקנים. **חובה בפרודקשן** (השרת לא יעלה בלעדיו) |
| `NODE_ENV` | `development` | ב־`production` השרת מגיש גם את `dist/` |
| `TRUST_PROXY` | – | `1` מאחורי reverse proxy, כדי שהגבלת הקצב תראה את כתובת ה־IP האמיתית |
| `ANTHROPIC_API_KEY` | – | מפתח ל־Claude API עבור שיחות הווידאו עם AI. בלעדיו `POST /api/call/turn` מחזיר 503 |
| `CALL_MODEL` | `claude-haiku-5-5` | המודל לשיחות הווידאו (מודל מהיר = תשובות מהירות) |
| `PREMIUM_EMAILS` | – | אימיילים של מנויי פרימיום, מופרדים בפסיקים (בלי תלות ברישיות). רק הם יכולים לקיים שיחות וידאו (עד 10 ביום); לאחרים `POST /api/call/turn` מחזיר 403 |
| `TZ` | `Asia/Jerusalem` | אזור הזמן לחישוב רצף ו־XP יומי כשהלקוח לא שלח תאריך מקומי |

## בדיקות ואיכות קוד

```bash
npm run typecheck  # tsc לווב ולשרת
npm run lint       # ESLint
npm test           # בדיקות הווב (Vitest) ואז בדיקות השרת (Vitest + supertest)
npm run test:e2e   # בדיקות קצה־לקצה (Playwright): מרים שרת עם DB בזיכרון + Vite, ומריץ ב־Chromium. לא מוריד דפדפנים – CHROMIUM_PATH או /opt/pw-browsers/chromium
npm run build      # בנייה של אפליקציית הווב ל־dist/
npm run check      # הכול ברצף
npm run format     # Prettier
```

ה־CI ב־GitHub Actions (`.github/workflows/ci.yml`) מריץ את כל השלבים האלה ובונה גם את ה־Docker image.

## הרצה בפרודקשן

```bash
npm install
npm run build
NODE_ENV=production JWT_SECRET=<סוד-ארוך> npm start
```

השרת מגיש את ה־API תחת `/api` ואת האפליקציה הבנויה מ־`dist/` על אותו פורט (ברירת מחדל http://localhost:3001).
`index.html`, `sw.js` והמניפסט נשלחים עם `no-cache`, וקבצי `assets/` (עם hash בשם) נשמרים במטמון לטווח ארוך.

## הרצה עם Docker

```bash
JWT_SECRET=$(openssl rand -hex 32) docker compose up --build
# פותחים http://localhost:3001
```

או בלי compose:

```bash
docker build -t baktana-english .
docker run -p 3001:3001 -e JWT_SECRET=<סוד> -v baktana-data:/app/data baktana-english
```

מסד הנתונים נשמר ב־volume בשם `baktana-data`. ל־image יש HEALTHCHECK על `/api/health`.

## האתר החי (GitHub Pages)

בכל דחיפה ל־`main` ה־workflow ‏`.github/workflows/pages.yml` בונה את האפליקציה ומפרסם אותה ב־
https://baktanaenglish-hub.github.io/baktana-english/ (עובר לדומיין https://baktanaenglish.co.il – ראו [docs/domain.md](docs/domain.md))

ב־GitHub Pages אין שרת. לכן ההרשמה, ההתחברות והליגה עובדים שם (ובאפליקציית האנדרואיד) דרך Supabase, אחרי שמגדירים אותו לפי [docs/supabase.md](docs/supabase.md). עד אז האפליקציה עובדת במצב אורח מלא (שיעורים, לבבות, XP, רצף, תרגול והתקנה בטלפון).
הפעלה חד־פעמית: ב־GitHub, ‏Settings → Pages → Source: **GitHub Actions**.

לבדיקה מקומית של אותה גרסה: `BASE_PATH=/baktana-english/ VITE_ENABLE_ACCOUNTS=false npm run build`.

## API בקצרה

| נתיב | הסבר |
|---|---|
| `GET /api/health` | בדיקת תקינות |
| `POST /api/auth/register` | הרשמה (מחזיר 201 עם טוקן) |
| `POST /api/auth/login` | התחברות |
| `GET /api/me` 🔒 | המשתמש וההתקדמות שלו |
| `DELETE /api/me` 🔒 | מחיקת החשבון וכל הנתונים שלו (עם אימות סיסמה) |
| `GET`/`PUT /api/progress` 🔒 | קריאה / העלאה ומיזוג של התקדמות |
| `POST /api/lessons/:lessonId/complete` 🔒 | רישום השלמת שיעור |
| `GET /api/leaderboard?period=` | הליגה האישית: שבוע / חודש / מצטבר (טוקן אופציונלי מסמן את השורה שלי) |
| `GET`/`POST /api/groups`, `POST /api/groups/join` 🔒 | הקבוצות שלי, יצירת קבוצה, הצטרפות בקוד |
| `GET /api/groups/:id/members`, `DELETE /api/groups/:id/membership` 🔒 | הדירוג בתוך קבוצה, עזיבה |
| `GET /api/groups/leaderboard?period=` | דירוג הקבוצות (ממוצע XP לחבר) |
| `GET`/`PUT /api/srs` 🔒 | קריאה / העלאה ומיזוג של מצב החזרה המרווחת |
| `POST /api/events` | קבוצת אירועי אנליטיקה (עד 50; טוקן אופציונלי) |

פירוט מלא, דוגמאות וקודי שגיאה: [docs/api.md](docs/api.md).

## הוספת תוכן

מוסיפים שיעור לקובץ היחידה ב־`src/data/units/` עם מילים (`words`) ומשפטים (`sentences`). התרגילים נוצרים ממנו אוטומטית.
ב־`alt` אפשר להוסיף תשובות נוספות שיתקבלו (למשל `I'm` במקום `I am`), וב־`heAlt` את הצורה העברית בנקבה. `src/data/content.test.ts` בודק את כל התוכן. לפני שכותבים תוכן כדאי לקרוא את מדריך הסגנון ב־[docs/curriculum.md](docs/curriculum.md).
